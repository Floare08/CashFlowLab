## 🎨 SPECIFICAȚII DESIGN

### Dimensiune
- **Format:** A4 (210 x 297 mm)
- **Orientare:** Portrait + Landscape (mix)
- **Pagini:** 6-8 pagini
- **Style:** Modern, professional, infographic-style

### Paleta de Culori
```
Primary Gold:    #D4AF37
Primary Purple:  #8A5FFF
Secondary Teal:  #00BCD4
Dark:            #1A1A2E
Text:            #1A1A1A
Light BG:        #F8F9FA
Accent Coral:    #FF6B6B
```

### Fonturi
- **Headers:** Montserrat Bold
- **Subheaders:** Montserrat SemiBold
- **Body:** Inter
- **Quotes:** Playfair Display Italic
- **Accents:** Space Mono (for code/templates)

## 🎯 ELEMENTE SPECIALE CANVA PRO

### 1. Animations (Pentru versiunea digitală)
- Page 2: Săgeți animate (Animate → Tumble)
- Page 3: Typewriter effect pe code block
- Page 5: Instagram stories animate

### 2. Smart Mockups
- File → Smart Mockups → Search "iPhone", "Browser", "Email"
- Importă design-ul pe device-uri reale

### 3. Brand Kit aplicat
- Logo în header-ul fiecărei pagini
- Culori consistente
- Fonturi aceleași peste tot

### 4. Charts & Graphs
- Page 8: Before/After chart
- Elements → Charts → Bar chart
