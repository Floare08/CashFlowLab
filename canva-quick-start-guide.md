## 🚀 START RAPID - MINI Kit (15 minute)

### PAS 1: Creează Designul (1 min)
1. **Canva.com** → Log in
2. **Create a design** → **A4 Document**
3. Click pe **File** → **Save** → "MINI Kit - CashFlowLab"

### PAS 2: Setează Culorile Brandului (2 min)
1. Click **Styles** (sidebar dreapta)
2. **Document Colors** → **Add new color**
3. Adaugă codurile:
   - `#D4AF37` (Gold)
   - `#8A5FFF` (Purple)
   - `#1A1A2E` (Dark)
   - `#F8F9FA` (Light background)

### PAS 3: Adaugă Fonturile (1 min)
1. Click **Text** → **Add a heading**
2. Schimbă fontul în **Montserrat Bold**
3. Pentru body: **Inter** sau **Open Sans**

### PAS 4: Construiește Pagina 1 (5 min)

Copiază din `canva-mini-kit-design.md`:

**HEADER:**
- Add heading: "MINI KIT"
- Font: Montserrat Bold, 48pt
- Color: Gold

**SUBTITLE:**
- Add subheading: "Quick Launch Checklist"
- Font: Montserrat Light, 24pt

**BADGE-URI:**
- Elements → Shapes → Rounded Rectangle
- Text: "$9 | 15 MINUTE | 3 STEPS"
- Border: Gold, 2px
- Fill: Transparent

**CHECKLIST:**
- Elements → Shapes → Square (for checkbox)
- Size: 24x24px, border gold
- Text lângă: Inter, 14pt

### PAS 5: Pagina 2 (4 min)
- Click **Add page** (bottom)
- Replică structura din design brief
- Adaugă "Cele 3 greșeli" în card-uri

### PAS 6: Export (2 min)
- **Share** → **Download**
- Format: **PDF Print**
- ✅ Done!

## 🎨 TIPS CANVA PRO

### Shortcut-uri Utile
| Acțiune | Shortcut |
|---------|----------|
| Copy | `Ctrl+C` |
| Paste | `Ctrl+V` |
| Duplicate | `Ctrl+D` |
| Delete | `Delete` |
| Group | `Ctrl+G` |
| Ungroup | `Ctrl+Shift+G` |
| Bring forward | `Ctrl+]` |
| Send backward | `Ctrl+[` |

### Elemente Care Impresionează

1. **Gradient Background**
   - Background → Color → Gradient
   - Purple → Dark: 45° angle

2. **Glass Morphism Cards**
   - Elements → Shapes → Rounded
   - Effects → Background blur
   - Border: 1px white, 50% opacity

3. **Gold Foil Text**
   - Text → Effects → Foil
   - Alege "Gold"
   - Add subtle shadow

4. **Smart Mockups**
   - File → Smart Mockups
   - Search: "iPhone", "MacBook", "Browser"
   - Importă design-ul pe device

5. **QR Codes**
   - Apps → QR Code
   - Paste link Gumroad
   - Generează automat

## 💡 Secretul Design-ului Profesional

**NU reinventa roata:**
- Folosește **Templates** Canva ca punct de start
- Adaptează culorile și fonturile
- Păstrează consistența între kituri

**Regula 60-30-10:**
- 60% culoare principală (background)
- 30% culoare secundară (cards)
- 10% accent (CTAs, highlights)

**White space e prietenul tău:**
- Nu umple fiecare pixel
- Lasă respirație între elemente
- Conținutul respiră = looks premium
