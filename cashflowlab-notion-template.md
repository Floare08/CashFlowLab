# 💡 Oferta Magnetică

⚠️ **Greșeala comună:** "vând ceva"

**Corect:** "Rezolv o problemă clară pentru un tip clar de om"

#### Completează tabelul:

| Întrebare | Răspunsul meu |
|-----------|---------------|
| ❗ Ce problemă are ACUM? | |
| 🎁 Ce rezultat concret promiți? | |
| ⏳ Timp până la rezultat? | |
| 📄 Format (PDF/Video/Call)? | |
| 💰 Preț estimativ? | |

#### Validare:

- [ ] Pot explica problema în 10 secunde
- [ ] Știu exact cine are problema (nu "oricine")
- [ ] Rezultatul este măsurabil (nu "mai bine")
- [ ] Prețul este sub €100 (pentru primul produs)

**Exemplu completat:**
- Cine: Freelanceri de design care vor mai mulți clienți
- Problema: Nu știu să facă outreach consistent
- Rezultat: 3 call-uri calificate/săptămână
- Timp: 14 zile
- Format: Template Notion + 3 video-uri
- Preț: €27


#### Completează:

**1. Sursă trafic:**

**2. Primul contact:**
Tip: ___ (video / post / reclamă)
Hook: ___
CTA: ___

**3. Landing page:**
URL: ___
Headline: ___
Lead magnet: ___

**4. Email sequence:**
- [ ] Email 1: Bun venit + livrare
- [ ] Email 2: Story + problemă
- [ ] Email 3: Soluție + CTA

**5. Ofertă plătită:**
Produs: ___
Preț: €___

**Exemplu:**
- Trafic: TikTok 3x/zi cu tips de design (15-sec)
