# MEDIUM CashFlowLab Kit

## 🚀 Funnel-ul care transformă vizitatorii în clienți — automat

Acest kit îți oferă structura completă de funnel + automatizări esențiale pentru a scala afacerea financiară.

---

## 📦 Ce conține acest kit:

### 1. Structură Completă Funnel (5 Pagini)
- **Opt-in Page** - Captare leads cu lead magnet
- **Tripwire Page** - Ofertă de intrare ($7-$27)
- **Sales Page** - Oferta principală, long-form
- **Order Bump & Upsell** - Crește valoarea coșului
- **Thank You Page** - Onboarding și următorii pași

Fiecare pagină include:
- Design complet responsive
- Copy framework inclus
- Elemente de conversie testate
- Variante A/B pentru testing

### 2. Automatizări de Bază (Workflow-uri gata configurate)
- **Welcome Sequence** - 3 emailuri de introducere
- **Abandoned Cart** - 2 emailuri recuperare coș
- **Post-Purchase** - 2 emailuri follow-up
- **Tagging & Segmentare** automată

Formate disponibile:
- ActiveCampaign
- ConvertKit
- Mailchimp
- GoHighLevel
- Zapier workflows

### 3. Template-uri Business (20+)
- Proposal template (PDF editabil)
- Contract template (Word)
- Invoice template (Excel)
- Client onboarding checklist
- Discovery call script
- 1-on-1 session template
- Monthly report template
- Financial calculator

### 4. Design Assets Extinse
- 20+ Canva templates social media
- 5 Ad creative templates (Facebook/Google)
- Lead magnet design templates
- Email header templates
- Presentation deck (20 slides)

### 5. Curs Video: "Funnel Fundamentals" (45 min)
- Cum funcționează un funnel de vânzări
- Cele 5 tipuri de funnel esențiale
- Metrici de urmărit
- Cum optimizezi conversiile

### 6. Bonusuri Exclusive
- Swipe file cu 50+ emailuri de succes
- Facebook Ads targeting cheat sheet
- Retargeting pixel setup guide
- Chatbot flow templates (ManyChat)
