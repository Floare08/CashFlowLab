**Tipografie:**

| Rol | Font | Greutăți | Utilizare |
|-----|------|----------|-----------|
| **Headings** | Playfair Display | 400, 500, 600, 700 | H1-H3, titluri secțiuni, citate |
| **Body Text** | Inter | 300, 400, 500, 600 | Paragrafe, body copy, UI elements |
| **Accent/Decorative** | Playfair Display Italic | 400, 500 | Cuvinte cheie în titluri, citate |

**Dimensiuni Font (Scale):**
- Hero Title: 48-56pt (Playfair Display 600)
- Page Title: 32-36pt (Playfair Display 500)
- Section Header: 24-28pt (Playfair Display 500)
- Subsection: 18-20pt (Inter 600)
- Body Large: 14-16pt (Inter 400)
- Body Regular: 11-12pt (Inter 400)
- Caption: 9-10pt (Inter 300, uppercase, tracked)

**Layout & Grid:**
- Format: A4 (210 × 297mm)
- Margini: 20mm (stânga/dreapta), 15mm (sus/jos)
- Grid: 12 coloane, 16px gutter
- Line height: 1.6 (body), 1.3 (headings)
- Spacing vertical: 8px base unit (multiples: 8, 16, 24, 32, 48, 64, 96)

• În materiale premium/luxury: 1.5X

## NOTE PENTRU DESIGNER

### Recomandări Generale de Design:

1. **Consistența Brandului:**
   - Folosește întotdeauna paleta de culori definită
   - Menține hierarhia tipografică consistentă
   - Asigură că logo-ul apare pe fiecare pagină (header sau footer)

2. **Whitespace:**
   - Nu te teme de spațiu gol — adaugă respirație
   - Minimum 24px între secțiuni majore
   - Marginea paginii: 20mm consistent

3. **Visual Hierarchy:**
   - Folosește contrastul de dimensiune pentru a ghida ochiul
   - Culorile accent (Gold, Purple) pentru elemente importante
   - Bold pentru acțiuni și CTA-uri

4. **Accesibilitate:**
   - Contrast minimum 4.5:1 pentru text
   - Font size minimum 9pt pentru body text
   - Evită text pe imagini complexe

### Mockup-uri Necesare:

**PDF #1:**
- Copertă pe fundal de hârtie texturată
- Diagramă spațiu de siguranță cu linii de construcție
- Cele 4 variații ale logo-ului pe diferite background-uri
- Exemple de card de vizită și letterhead

**PDF #2:**
- Wireframe landing page realist
- Timeline vizual pentru cele 24 de ore
- Mockup postări social media
- Exemple de before/after branding

**PDF #3:**
- Infografic cu cele 5 faze
- Dashboard KPI vizual
- Timeline lansare
- Value ladder diagram

### Elemente Interactive (dacă PDF-ul suportă):

- Link-uri clickabile către resurse
- Table of contents cu bookmarks
- Form fields pentru checklist-uri (dacă e fillable PDF)

### Format de Livrare:

- **Print:** PDF high-quality (300 DPI), CMYK, with bleed
- **Digital:** PDF interactive (150 DPI), RGB, optimized for web
- **Source files:** Adobe InDesign sau Figma cu toate asset-urile organizate
