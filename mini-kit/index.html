Conținut clar

MINI este un pachet digital compact: PDF, template Notion și patru emailuri. Nu îl prezentăm ca pachet de branding, logo-uri sau landing pages, pentru că acestea nu fac parte din livrabilele curente verificate.

Întrebări frecvente

Ce format au fișierele? +

Primești un PDF, un fișier Markdown pentru Notion și patru fișiere text pentru emailuri.

Trebuie să știu programare? +

Nu. MINI este un checklist și un set de texte/template-uri, nu un proiect de programare.

Cât durează să-l folosesc? +

Checklist-ul principal este gândit pentru o verificare rapidă, de aproximativ 15 minute. Implementarea corecțiilor depinde de proiectul tău.

Cum primesc kitul? +

Achiziția se face prin Gumroad, iar livrarea este digitală conform checkout-ului produsului.
