# CANVA PRO - PRO Kit Design Brief
## "Sistemul Complet de Lansare"

---

## 🎨 SPECIFICAȚII PREMIUM DESIGN

### Dimensiune
- **Format:** A4 + A3 (pentru diagrame)
- **Orientare:** Portrait + Landscape
- **Pagini:** 15-20 pagini
- **Finisaj:** Premium, corporativ, high-ticket

### Paleta Premium
```
Gold Metallic:   #C9A227
Deep Purple:     #6B46C1
Midnight Blue:   #1E1B4B
Rich Black:      #0A0A0A
Pearl White:     #FAFAFA
Accent Teal:     #14B8A6
Success Green:   #10B981
Alert Orange:    #F97316
```

### Fonturi Premium
- **Headlines:** Playfair Display Bold (elegant)
- **Subheads:** Montserrat Bold
- **Body:** Inter / Source Sans Pro
- **Accents:** Cormorant Garamond (italic quotes)
- **Code:** Fira Code (for technical sections)

### Textură & Efecte
- **Background:** Subtil grain texture (5% opacity)
- **Cards:** Glass morphism effect (Canva Pro)
- **Gold accents:** Metallic gradient
- **Shadows:** Multi-layer, soft
