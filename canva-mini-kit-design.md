## 🎯 INSTRUCȚIUNI CANVA

### 1. Creează Design Nou
- File → Create new design → A4 Document

### 2. Setează Culorile
- Click pe element → Color → Add new brand color
- Adaugă toate codurile de mai sus

### 3. Adaugă Fonturile
- Text → Upload font (dacă nu sunt default)
- Montserrat, Inter, Playfair Display sunt pe Canva Pro

### 4. Elemente Grafice
- **Checkboxes:** Elements → Search "checkbox" → alege square
- **Icons:** Elements → Search "rocket", "check", "error"
- **Lines:** Elements → Lines → alege thickness 2px
- **Shapes:** Elements → Shapes → rounded rectangles pentru cards

### 5. Brand Kit (Salvează!)
- Brand Kit → Upload Logo
- Setează culorile brandului
- Salvează fonturile

---

## 💡 TIPS CANVA PRO

1. **Folosește Brand Kit** - Logo, culori, fonturi salvate
2. **Smart Resize** - Poți face rapid variantele pentru MEDIUM și PRO
3. **Animation** - Pentru versiunea digitală (PDF interactiv)
4. **Background Remover** - Dacă ai poze de produs
5. **Magic Write** - Ajutor la copy (dar verifică!)
