## 📄 Template-uri incluse

### 1. Landing Page Template (HTML Copy-Paste)

```html
<!DOCTYPE html>
<html lang="ro">
<head>
  <meta charset="utf-8">
  <title>[NUME PRODUS] - [REZULTAT PRINCIPAL]</title>
  <meta name="description" content="[PROBLEMA] + [SOLUȚIE] + [DOVADĂ]">
</head>
<body style="font-family:system-ui;max-width:600px;margin:0 auto;padding:40px 20px;">
  
  <!-- HERO -->
  <h1>[PROBLEMA] îți [CONSECINȚA NEGATIVĂ]?<br>
  <em style="color:#8A5FFF;">[SOLUȚIE] în [TIMP]</em></h1>
  
  <p>[Descriere scurtă - 2 propoziții max]</p>
  
  <!-- DOVADĂ -->
  <div style="background:#f5f5f5;padding:20px;border-radius:8px;margin:20px 0;">
    <p>"[Testimonial scurt - 1-2 propoziții]"</p>
    <p><strong>- [Nume], [Rezultat]</strong></p>
  </div>
  
  <!-- CTA -->
  <a href="[LINK CHECKOUT]" style="display:inline-block;background:#8A5FFF;color:white;padding:16px 32px;border-radius:8px;text-decoration:none;font-weight:bold;">
    [ACȚIUNE] →
  </a>
  
  <p style="font-size:14px;color:#666;">✓ [GARANȚIE SIMPLĂ] • ✓ [TIMPI DE LIVRARE]</p>

</body>
</html>
```

**Instrucțiuni:**
1. Copiază codul într-un fișier .html
2. Înlocuiește [CAPS LOCK] cu conținutul tău
3. Testează pe telefon înainte să publici
4. Nu adăuga mai mult de 3 secțiuni suplimentare

## ✅ Checklist-uri esențiale

### Pre-Launch (15 minute)
```
□ Framework completat (Problemă → Promisiune → Dovadă → CTA)
□ Landing page testat pe mobil
□ Email announcement salvat în drafts
□ 3 posturi social programate
□ 1 testimonial/proof gata de folosit
□ Preț și deadline confirmate
```

### Post-Launch (24 ore + 7 zile)

**24h:**
```
□ Metrici verificate (views, clicks, conversions)
□ Reply la toate mesajele/comentariile
□ Bug-uri critice fixate
□ 1 share pe story (behind the scenes)
```

**7 zile:**
```
□ Optimizat 1 element (headline sau CTA)
□ Adăugat 1 testimonial nou
□ Documentat lecțiile învățate
□ Plan pentru următoarea lansare
```

## 🚫 Anti-Patterns (Top 5 greșeli)

| # | Greșeală | Cost | Soluție |
|---|----------|------|---------|
| 1 | Prea multe CTA-uri | Confuzie, 0 conversii | 1 CTA per secțiune |
| 2 | Promisiuni fără dovadă | Nicio vânzare | Fiecare promisiune = 1 număr |
| 3 | Template fără logică | Copy-paste prost | Înțelege înainte să copiezi |
| 4 | Totul pentru toți | Audiență diluată | 1 persona per produs |
| 5 | Design înainte de trafic | Pierdere timp | 80/20 rule (trafic vs design) |
